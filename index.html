Was hier nicht läuft — und warum

Der Agent selbst braucht Python und eine Datenbank. GitHub Pages liefert nur Dateien aus, führt aber nichts aus. Lokal starten:

git clone … && cd masteragent && bash run.sh

Die 3D-Rekonstruktion braucht eine Nvidia-Grafikkarte und mehrere Gigabyte Modellgewichte. Der Kamera-Scan bereitet die Aufnahme vor; gerechnet wird dort, wo eine Grafikkarte steht.
